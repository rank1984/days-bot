# DAYS-BOT V6 — EARLY Discovery Spec (DRAFT)

**Status:** SPEC ONLY — no production code.  
**Baseline required:** 50 VALID EXECUTABLE outcomes from V5.0.6.  
**Author decision:** 2026-09-28.

---

## 1. Purpose

Detect stocks **before** they move — where the conditions for a move
are forming, not where the move has already happened.

V5.0.6 (MOMENTUM scanner) answers: "what moved and is still moving?"  
V6 EARLY answers: "what is coiled and about to move?"

**EARLY is an additional track — NOT a replacement for V5.0.6.**

---

## 2. Non-Goals

- Replace V5.0.6
- Change existing scoring / thresholds / Swing
- Trade based on news alone (news is catalyst input, not entry signal)
- Promote EARLY candidate to Trade before technical trigger fires
